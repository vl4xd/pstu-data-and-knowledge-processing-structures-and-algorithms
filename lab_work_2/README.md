
## Запуск приложения

### 1. Перейти в дирректорию `\src`:
```bash
cd lab_work_2/src/
```
### 2. Запуск задания №1:
**Запуск примера:**
```bash
py task_1/main.py
```
### 3. Запуск задания №2 и задания №3:
**Запуск приложеня:**
```bash
py task_2_3/main.py
```
**Запуск тестов:**
```bash
py task_2_3/test_math_parser.py
```

### 4. Получения отчета о покрытии
**Создание виртуального окружения:**
```bash
py -m venv venv
```
**Активация виртуального окружения:**
```bash
source venv/Scripts/activate
```
**Установка зависимостей:**
```bash
pip install -r requirements.txt
```
**Запуск тестирования:**
```bash
coverage run --source=task_2_3/math_parser -m unittest discover -s task_2_3
```
**Создание отчета:**
```bash
coverage html
```
**Путь к отчету (открыть как файл):**
```bash
htmlcov/index.html
```
