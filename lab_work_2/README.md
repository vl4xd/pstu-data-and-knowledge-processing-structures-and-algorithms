# Лабораторная работа №2 *(Деревья)*

## Структура проекта:

```
/lab_work_2
├── docs/
├── src/
|   ├── task_1/                         # Задание №1
|   |   ├── main.py                     # запуск задания
|   |   ├── splay_node.py               # реализация узла Splay-дерева
|   |   └── splay_tree.py               # реализация Splay-дерева
|   └── task_2_3/                       # Задание №2 и Задание №3
|       ├── math_parser/                # реализация дерева разбора выражения
|       |   ├── tree_objects/           # объекты дерева разбора выражения
|       |   |   ├── addend_node.py      # реализация узла "Слагаемое"
|       |   |   ├── expression_node.py  # реализация узла "Выражение"
|       |   |   ├── factor_node.py      # реализация узла "Множетель"
|       |   |   ├── letter_node.py      # реализация узла "Переменная"
|       |   |   ├── number_node.py      # реализация узла "Число"
|       |   |   └── utils.py            # утилиты дерева разбора выражения
|       |   ├── test_math_parser.py     # тестирование парсера выражения
|       |   └── math_parser.py          # реализация парсера выражения
|       └── main.py                     # запуск задания
├── .gitignore
└── README.md
```

## Запуск приложения

### 1. Перейти в дирректорию `\src`:
```bash
cd lab_work_2/src/
```
### 2. Запуск задания №1:
**Запуск примера:**
```bash
py task_1/main.py
```
### 3. Запуск задания №2 и задания №3:
**Запуск приложеня:**
```bash
py task_2_3/main.py
```
**Запуск тестов:**
```bash
py task_2_3/math_parser/test_math_parser.py
```
